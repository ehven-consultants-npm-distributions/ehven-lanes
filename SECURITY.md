# Security policy

## Supported versions

Until the package reaches version 1.0.0, security fixes are applied to the latest published minor version.

| Version | Supported |
|---|---|
| Latest `0.x` minor | Yes |
| Older `0.x` minors | No |

## Reporting a vulnerability

Do not report a suspected vulnerability in a public issue.

Use GitHub private vulnerability reporting on the [public distribution repository](https://github.com/ehven-consultants-npm-distributions/ehven-lanes/security/advisories). Sign in and choose **Report a vulnerability**. Reports are private to the reporting collaboration and authorized maintainers; do not include credentials or unrelated private data.

For a routine usage problem, use the repository’s public issue tracker. No response-time guarantee is offered.

Include:

- The affected package version.
- The relevant installation or delivery method.
- A reproducible demonstration.
- The practical impact.
- Any suggested mitigation.

This package contains CSS rather than executable browser JavaScript, but supply-chain, publication, integrity, and unexpectedly unsafe rendering issues are still treated as security concerns.
